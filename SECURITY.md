# Security

quickcheck reads SQL and reports diagnostics. It has no runtime dependencies,
makes no network calls and writes no files. The VS Code extension, CLI and
library all run entirely on your machine.

To report a vulnerability, use GitHub's private reporting (the "Report a
vulnerability" button on this repository's Security tab) rather than a public
issue. Expect an answer within two weeks. This is a single-maintainer project.

Do not include proprietary SQL in a report. See rule 1 in
[`CONTRIBUTING.md`](CONTRIBUTING.md).
